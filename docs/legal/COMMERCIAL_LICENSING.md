## 2. Commercial Licensing Models

1. **Single-Company Self-Hosted Enterprise License:** Grants an individual construction firm rights to compile, configure, and run Construction Diary strictly for internal corporate projects on its own GCP/private cloud infrastructure.
2. **Commercial Acquisition / Source Code Buyout:** Transfers or assigns commercial IP / white-label hosting rights under a separately executed Purchase Agreement.
3. **Restricted Evaluation:** Setting `NEXT_PUBLIC_DEMO_MODE=true` allows prospective licensees to evaluate the Web UI and offline PDF report rendering locally on seeded sample data without conveying production deployment rights.
